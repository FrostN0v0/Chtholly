## 🛠️ 快速开始

需要 Python 3.10+ 与 [uv](https://docs.astral.sh/uv/)。

```shell
git clone https://github.com/FrostN0v0/Chtholly.git
cd Chtholly
uv sync --all-extras
uv run entari run
```

更多框架用法见 [Entari 文档](https://arclet.top/tutorial/entari/)。
